# Contributing

Friendly contributions are welcome through issues and pull requests.

## Rules

1. Do not commit secrets, personal data, production exports, or unpublished media.
2. Keep `main` deployable.
3. Run `npm run check` before requesting review.
4. Treat `prototypes/tresh-editor-v0.html` as an immutable UX reference; improvements belong in the real React application.
5. Do not add arbitrary HTML, JavaScript, or CSS execution to the editor document model.

The project owner decides what becomes canonical.
